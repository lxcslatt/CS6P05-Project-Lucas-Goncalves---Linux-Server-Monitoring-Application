# CS6P05-Project-Lucas-Goncalves---Linux-Server-Monitoring-Application


This repository is my staging environment for my Linux Server Security and Networking Monitoring Application as part of my project for my final year in BSc Cybersecurity and Networking.
at LMU.

This application aims to answer the question does a centralised monitoring environment aid people who need to oversee a Linux server metrics such as network connectivity, security events and system peformance
This project explores how Python can be used to create such aim as this will be a full stack application written in python. 

Project is currently in early development stages, with initial and fundamental features being tested.
